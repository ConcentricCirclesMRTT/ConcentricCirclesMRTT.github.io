# NeuBE-Structural-Rebuild Showcase

比赛展示页，以 `release/NeuBE-Structural-Rebuild` 的 fully open-source Skill 为主叙事，角钢塔作为第一个高难度成功样例。页面强调证据、语义、约束、复核和发布状态之间的可追溯关系。

直接打开 `index.html` 即可浏览；开发预览可在本目录启动静态服务器：

```bash
python3 -m http.server 8892
```

页面使用 NeuBE SR banner，以及已复制到本目录 `assets/` 的角钢塔图纸、交叉假设、Semantic IR、验证门禁和协调级三维模型截图。展示脚本见 `STORY_SCRIPT.md`。
